## 표현·공개 정보 정리

- Overview의 Redux는 React Native 앱 내부에 표시했습니다. 별도 서버나 백엔드 데이터 계층으로 표시하지 않습니다.
- Django Admin은 Django 내부 관리자 기능으로 묶었습니다.
- Hackle은 별도 실험·계측 서비스이며 사용자 화면과의 관계만 개념적으로 표시했습니다. 구체적인 Web/App SDK 호출 지점은 원본 근거가 없어 추정하지 않았습니다.
- DB 제품·배포 구조·원본 API 경로는 추가하지 않았습니다. 기존 모두닥 경력의 DB 제품 표기도 ORM 기술로 대체했습니다.
- DB 도식에서 실제 리뷰·진료 관계, 카디널리티, 실제 모델 수·FK 연결선을 제거했습니다. A/B/C는 모델 수와 무관한 예시이며 After 카드들은 작업 개념을 나타냅니다.
- 데이터 불일치가 발생했다거나 기존 설계가 잘못됐다는 문구를 제거했습니다. 경력 요약도 확장성 중심 표현으로 맞췄습니다.
- 공개 화면에 이전 건수·로딩 시간·80%·실험 성과를 표시하지 않습니다. 원본 소스·SQL·실험 키·운영 규칙·실데이터는 사용하지 않았습니다.
- 모든 페이지에서 Problem/Solution/Result를 강제하지 않습니다. DB는 목적/구현/검증, 성능은 3개 기술 경로, 개인화는 2개 사례, Features는 구현 카드로 구성했습니다.
- 실제 서비스 캡처 없이 기능 카드와 가상 관리자 예시를 사용합니다. 기존 서비스에 새 On-Demand Loading을 구현하거나 서비스 코드를 수정하지 않았습니다.
- My Garage와 다른 프로젝트 콘텐츠는 이번 수정에서 변경하지 않았습니다. 간격 CSS는 모두닥 슬라이드에만 적용했습니다.

## 별도 확인이 필요한 사항

1. **로딩 지표와 수치 공개 여부:** 제공한 약 9초→2초는 로딩 시간 약 77.8% 감소이며, 약 80%는 이를 반올림한 표현입니다. ‘속도 80% 향상’과 ‘시간 약 80% 감소’는 같은 의미가 아닙니다. 측정 범위·조건·시점이 동일한지는 기록 없이 확인할 수 없습니다. 회사의 공개 허용 여부도 미확인입니다. 현재 대체 문구는 ‘병원 상세 페이지의 초기 이미지 로딩 지연 개선’입니다. 공개 근거 확보 시 측정 대상에 맞춰 ‘로딩 시간 약 80% 단축’처럼 표현할 수 있습니다.
2. **내부 참고 경험:** 기존 1:N 모델링과 대량 이전 경험은 이전 내부 검토 초안에 보존합니다. 공개 도식으로 재구성하지 않습니다.
3. **Hackle 실제 호출·계측 경로:** Web/App 중 실제 SDK 호출부와 이벤트 수집 경로는 원본 조사로 확인해야 합니다. 현재 개념도의 일반적인 사용자 화면 연결을 실제 호출 관계 검증으로 읽으면 안 됩니다.
4. **실제 서비스 캡처:** 추후 사용한다면 공식 공개 범위·사용 권한·개인정보 여부를 확인합니다. 이번 작업에는 사용하지 않았습니다.
5. **재직 기간:** 기존 경력 2021.03~08과 프로젝트 2021.03~09의 차이는 이번 명세에 없으므로 임의로 통일하지 않았습니다.

## 최종 5장 압축

최신 사용자 요청에 따라 6장에서 Features를 제거하고 Overview에 상세·검색·리뷰·갤러리·앱 홈·배너 범위를 통합했습니다. 최신 구성은 Overview / DB Migration / Performance / Admin / A/B Testing & Personalization입니다.

제목은 다음 문장으로 복원했습니다.

1. 웹·앱 주요 기능부터 백엔드 데이터 처리까지 개발했습니다.
2. 모델 간 관계를 재설계하고 기존 데이터를 마이그레이션했습니다.
3. 이미지 조회와 로딩 시점을 개선해 초기 로딩 시간을 단축했습니다.
4. 동적 필터링으로 관리자 검수 업무를 간소화했습니다.
5. A/B 테스트로 사용자 행동을 계측하고, 홈 화면을 개인화했습니다.

Overview는 소개·업무 4줄을 유지합니다. DB·성능·관리자는 Problem/Solution/Result를 복원하고, Hackle·Redux는 각각 독립된 Problem/Solution/Result로 설명합니다. 모델 변경 시 데이터 보존을 DB 이전 과제로 삼아 기존 설계를 비판하지 않습니다.

도식은 같은 Group/Card·흰 배경·연회색 테두리·6px 카드 모서리·12px 제목·10px 설명·같은 간격으로 통일했습니다. 파란색은 공통 정보 분리, 대표 조회·지연 로딩, 필터 QuerySet, 실험 분기·Redux Store 등 핵심 처리에만 적용합니다. 성능 슬로건, 가상 관리자 화면, Features 구현 카드 및 관련 미사용 스타일을 제거했습니다.

이번 요청에 따라 Overview DB는 Relational Database로 변경했습니다. Django Admin은 Django 백엔드 내부 기능으로, Redux는 앱 내부 상태 관리로, Hackle은 외부 실험 시스템으로 표시합니다. 실제 DB 제품·SDK 호출 지점 검증을 새로 수행한 것으로 설명하지 않습니다. 9초→2초는 공개 허용·측정 범위 확인 항목으로 유지하고 화면에는 정성 성과만 표시합니다.

검증: 타입 검사·ESLint·도식/5장 콘텐츠 검사 통과. 1280px 데스크톱 5개 탭, 이전 버튼 5→1, 다음 버튼 1→5 이동과 양 끝 비활성 확인. 실제 390px·320px에서 각 5장 가로 넘침 없음. 미리보기 `modoodoc-five-page-preview.png`. My Garage와 다른 프로젝트 콘텐츠는 이번 변경에서 수정하지 않았습니다.
